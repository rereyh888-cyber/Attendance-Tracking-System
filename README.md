## 📌 Attendance Tracking System  
**Collaborative Major Subject Project | Completed during 3rd Year – 1st Semester**

This is a web-based attendance tracking application developed as part of a multi-semester collaboration guided by our major subject instructor, Prof. Lucman Abdulrachman. The system is designed to provide teachers with an efficient digital dashboard to track student attendance, monitor statistics, and manage classroom data effectively.

### 🏗️ Project Structure & Architecture

- **Frontend Design:** Built using the Quasar Framework and Vue.js for a modern and responsive user interface.  
- **Type Safety:** Utilized TypeScript to maintain clean code architecture and reliable component scripting.  
- **Backend Database:** Integrated with Firebase for secure data hosting, authentication, and real-time attendance tracking updates.  

### 👨‍💻 My Contributions — Quality Assurance

- **Quality Assurance Testing:** Performed system testing to identify bugs, interface issues, and functionality errors before deployment.  
- **System Evaluation:** Assisted in checking user workflows, validating attendance data accuracy, and ensuring responsive interface behavior across different views.  
- **Collaboration & Documentation:** Worked closely with team members to report issues, suggest improvements, and help maintain overall system reliability and usability.
